# WayneRing AI Voice

WAYNERING – AI CALLING PLATFORM WEBSITE DESIGN PROMPT

Create a complete, premium, highly interactive, conversion-focused SaaS website for WayneRing – AI Calling Platform.

Reference the existing WayneRing application:
https://ringwave-flow.lovable.app/

The website must visually match the existing WayneRing application as closely as possible. Analyze and reuse the same overall design language, including its primary colors, secondary colors, gradients, typography style, border radius, card design, shadows, button styles, icons, spacing, and modern SaaS aesthetic.

The final result should feel like the official marketing website for the WayneRing AI Calling software.
